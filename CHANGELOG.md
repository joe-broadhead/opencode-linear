# Changelog

All notable changes to this plugin are recorded here, one section per release, newest first.

## 0.0.0 (unreleased)

The first release as `@we-the-rebel-alliance/linear-plugin`, on OpenCode 2.4.1.

- Target OpenCode 2.4.1 exactly: `>=2.4.1 <2.5.0`, tested on 2.4.1 only.
- Move to `we-the-rebel-alliance/linear-plugin` and restart the version at `0.0.0`.
- Class Linear's four deletes and `merge_diff` as `destructive` in the tools RPC.
- Move the issues read into Code Mode as `tools.linear.issues`, and print one namespace line instead of one per access value.
- Remove the deprecated `read` and `write` access values and the separate app guide.
